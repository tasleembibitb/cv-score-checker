# CV Score Checker

Does your CV match the job? Paste your CV and the job description and get a score out of 100, with matched and missing keywords and tips to improve.

## Features

- **Match score (0–100)** with a clear verdict: Strong Match, Good, Needs Work or Weak Match
- **Keyword match** — finds the important words in the job description and shows which ones your CV has and which ones it is missing
- **Score breakdown** — keyword match (70%), CV sections (15%), CV length (15%)
- **Matched / missing keyword chips** so you can see the gaps at a glance
- **Improvement tips** — generated from your actual result (missing contact info, experience, education, skills, or length)
- **Load Sample** button with fictional demo data
- Everything runs in your browser — your CV text is never sent anywhere

## How to use

1. Open `index.html` in any browser — no install needed.
2. Paste your CV in the left box and the job description in the right box.
3. Click **Check My Score**.
4. Add the missing keywords naturally into your skills and experience, then check again.

## Tech

HTML, CSS and vanilla JavaScript. No libraries, no build step.

## Sample data

The **Load Sample** button fills in a fictional CV ("Ayesha Khan", demo email and phone) and a fictional Frontend Developer job description, for demo only.
